# 🏦 Bank Customer Churn Prediction

## 📌 Project Overview

This project focuses on predicting whether a bank customer will churn (leave the bank) using Machine Learning techniques. It is a real-world business problem that helps financial institutions improve customer retention.

---

## 🎯 Objectives

* Perform Exploratory Data Analysis (EDA)
* Build multiple Machine Learning models
* Compare model performance
* Identify the best model for churn prediction

---

## 📊 Dataset Description

The dataset contains customer information such as:

* Credit Score
* Geography
* Gender
* Age
* Tenure
* Balance
* Number of Products
* Estimated Salary
* Target Variable: **Exited (Churn)**

## ⚙️ Models Used

* Logistic Regression
* Random Forest Classifier
* Gradient Boosting Classifier
* Artificial Neural Network (ANN)

---

## 📈 Model Performance

| Model               | Accuracy   | ROC-AUC    |
| ------------------- | ---------- | ---------- |
| Logistic Regression | 0.8080     | 0.7747     |
| Random Forest       | 0.8640     | 0.8522     |
| Gradient Boosting   | **0.8700** | **0.8708** |
| ANN                 | 0.8545     | 0.8528     |

🏆 **Best Model:** Gradient Boosting

---

## 🧠 Key Insights

* Customers with higher balances and age groups showed higher churn tendency
* Geography plays a role in churn behavior
* Ensemble models performed better than linear models
