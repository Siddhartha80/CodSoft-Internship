# Data

The dataset is not committed to this repository. To run the notebook, download the **Genre Classification Dataset (IMDb)** from [Kaggle](https://www.kaggle.com/search?q=genre+classification+dataset+imdb) and place the following files in this folder:

```
data/
├── train_data.txt   # ID ::: TITLE ::: GENRE ::: DESCRIPTION
└── test_data.txt    # ID ::: TITLE ::: DESCRIPTION
```

Fields are separated by ` ::: `, which is how the notebook parses them.
