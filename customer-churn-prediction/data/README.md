# Data

The dataset is not committed to this repository. To run the notebook, download the **Bank Customer Churn (Churn_Modelling)** dataset from [Kaggle](https://www.kaggle.com/search?q=churn+modelling+bank+customer) and place the file here:

```
data/
└── Churn_Modelling.csv
```

The file contains 10,000 customers and 14 columns, with `Exited` as the target.
